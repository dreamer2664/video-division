# FOUR SECONDS AHEAD / build notes

This package draws every frame from Python/Pillow vector primitives; it uses no stock or external image/audio assets. Voice is generated by Edge TTS (`en-US-ChristopherNeural`, rate −8%, pitch −4 Hz). `sound.py` synthesizes the drone and relay clicks deterministically from oscillators. `render.py` burns every camera timestamp and the captions into the picture and encodes vertical and landscape MP4s.

From this directory's parent (the package directory), install Python dependencies and provide FFmpeg 7+:

```bash
python3 -m pip install -r project/requirements.txt
FFMPEG=/path/to/ffmpeg ./render.sh
```

`render.sh` regenerates `assets/narration.wav`, `assets/score.wav`, `assets/final_mix.wav`, both MP4s, and four evidence stills; network access is required for Edge TTS. It writes exact spoken cue onsets to `project/voice_cues.csv` and matching caption changes (including intentional silent beats) to `project/caption_cues.csv`. Caption timing follows the words across hard cuts. Output is deterministic except for the neural speech service. Exact clock arithmetic is in `project/render.py`: each integer video frame computes `feed_ms = wall_ms + 4000`. `HERO-01-open-palm.png` is frame 1368 (00:45.600) in the vertical master.

The project is procedural animation, not a continuous live-feed simulation. Feed panels are synchronized representations driven by the same integer-frame clock and a shared timeline. Each timecode is rendered from that clock, not an independent software clock.
