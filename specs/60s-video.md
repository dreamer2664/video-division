> **Current gate — DIRECTIVE-2026-11-01-house-look.** This directive supersedes conflicting legacy concessions below: 1920×1080 landscape,30fps,60s; photographic night plates,33³ LUT grading, moving weather/camera, word-boundary captions tied to actual speech, committed narration/dialogue stems and telemetry. Reject portrait1080×1920 or vector-flat submissions on sight, without extended audit. Retain H.264/yuv420p/faststart,AAC48kHz stereo,-16±0.5LUFS,TP≤-1dBTP and full black/freeze gates. No720p fallback. See `../DIRECTIVE-2026-11-01-house-look.md` for story, visual and sound requirements. MARK FIVE is the approved reference, not permission to copy its plot.

The division's first real output. Every number here is checkable by `ffprobe` or by eye.

## Format
| property | requirement |
|---|---|
| duration | **58.0–62.0 s** exactly (no rounding up in the report) |
| container / codec | MP4, H.264 (libx264), yuv420p, faststart |
| resolution | 1920×1080 at 30 fps (720p30 acceptable if the sandbox cannot hold 1080p — say so if you fall back) |
| audio | 48 kHz stereo AAC, **-16 LUFS integrated** target, true peak ≤ -1 dBTP, no clipping |
| size | < 90 MB, or attach as a GitHub Release asset and commit the link |

## Content
- A **complete piece**, not a slideshow: a beginning that earns attention, a middle that develops one idea, an end that lands. Pick your own subject; write it down in `script.md` before you render.
- Text on screen must be legible at 100% on a laptop: minimum 40 px at 1080p, high contrast.
- No AI-generated voice claiming to be a real person. Synthetic narration is allowed only if it is clearly a designed element, and any music/SFX must be freely licensed or generated by you — record the source and licence in `QA.md`.

## Evidence (all committed)
1. `video.mp4` (or release link) — the deliverable.
2. `script.md` — narration/copy + shot list, written before rendering; timings per shot.
3. `render.sh` **or** a documented project — reproducing the video from the repo alone.
4. `QA.md` — measured: duration, resolution, fps, codec, audio loudness; plus a blunt self-review ("what is weak: …").
5. `ffprobe` output pasted verbatim into `QA.md`.
6. At least 3 stills (`stills/01.png` …) proving the picture is real.

## Verification commands (paste the output in QA.md)
```bash
ffprobe -v error -show_entries format=duration,size:stream=codec_name,width,height,r_frame_rate,codec_type -of default=noprint_wrappers=1 video.mp4
ffmpeg -v error -i video.mp4 -af loudnorm=print_format=summary -f null - 2>&1 | tail -12
```

## Non-negotiables
- No stock footage you did not licence. No watermarks. No black or frozen frames > 0.5 s.
- Captions: burn in or ship an `.srt`. If narration exists, subtitles are mandatory.
- Nobody publishes anything anywhere. This is a sample.
